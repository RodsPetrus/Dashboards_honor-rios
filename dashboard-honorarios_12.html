Como atualizar os dados

guia para manutenção recorrente do dashboard

Passo a passo para atualização

  1. Abra a planilha 2024 – Reviravolta – Gestão do custo & Monitoramento de honorários.xlsx
  2. Certifique-se de que os novos meses estão lançados na aba Detalhamento, nas colunas correspondentes ao mês/ano
  3. Envie a planilha atualizada para o Claude junto com esta mensagem:

    "Atualize o dashboard de honorários com os novos dados desta planilha. Mantenha o layout e as configurações atuais."
  4. O Claude irá: verificar automaticamente os novos meses disponíveis, recalcular todos os totais e estatísticas, gerar um novo arquivo HTML atualizado

O que será preservado a cada atualização

  1. Layout, cores e identidade visual Move Social
  2. Filtro de período (expandido automaticamente com novos meses)
  3. Toggle institucional (com/sem R$4.000)
  4. Todas as abas: Evolução, Comparação, Projetos e Dispersão
  5. Instrução de atualização (esta aba)

Atenção ao lançar novos dados

  1. Novos projetos devem ser lançados na mesma aba Detalhamento, seguindo o padrão existente (sócio na col A, projeto na col B, valores nas colunas de mês)
  2. A linha Institucional deve continuar sendo lançada separadamente para que o toggle funcione
  3. Projetos que se repetem com contratos distintos podem ter o mesmo nome na planilha — o sistema os trata como entradas independentes
